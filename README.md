# GenerativeAI_A

This repository contains assignments from the **Generative AI** course.

## Files

### `CNN_1.ipynb`
- **Task**: CNN for CIFAR-10 image classification  
- **Highlights**:
  - Preprocessing with normalization & label encoding  
  - CNN with convolutional blocks, batch norm, dropout & dense layers  
  - Achieved **83.6% accuracy** on test set  
  - Ablation studies on learning rate, batch size, filters, and depth  
  - Feature map visualizations of hierarchical representations  

### `RNN_1.ipynb`
- **Task**: RNN (LSTM) for Next-Word Prediction on Tiny Shakespeare dataset  
- **Highlights**:
  - Character-level tokenization & embedding  
  - LSTM with 1024 hidden units, dropout, and softmax output  
  - Achieved **77% validation accuracy** with **2.23 perplexity**  
  - Generated coherent Shakespeare-style text  
  - Ablation showed performance drop with smaller hidden size
